# BORNLY

App de acompanhamento gestacional em Expo (React Native), para iOS, Android e web.

```bash
npm install
npx expo start
```

- `app/`: rotas. O cadastro inicial fica na raiz e as telas com navegação inferior em `app/(app)/`.
- `src/content.ts`: textos e dados de exemplo.
- `src/store.tsx`: estado do app, ainda só em memória.
- `src/ui.tsx` e `src/theme.ts`: componentes, cores e fontes.
